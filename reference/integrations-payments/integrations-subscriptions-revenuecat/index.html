    make_revenuecat_webhook_router ¶

    make_revenuecat_webhook_router(
    *,
    inbox: WebhookInbox[Any],
    secret: SecretSource | None,
    signing_secret: SecretSource | None = None,
    on_recorded: Callable[[UUID], Awaitable[object]] | None = None,
    path: str = "/webhooks/revenuecat",
    tags: list[str] | None = None,
    include_in_schema: bool = True,
    tolerance_seconds: int = DEFAULT_SIGNATURE_TOLERANCE_SECONDS,
    docs_locale: str | None = None,
) -> APIRouter

    Mount the whole RevenueCat webhook: authenticate, record, answer 200.

    The route does no business logic. It records the event in inbox under (provider="revenuecat", external_id=event.id) with the body's model_dump — which leaves subscriber_attributes out — and answers 200. A repeated event.id records nothing and still answers 200. Processing happens later, through :meth:~tempest_fastapi_sdk.db.WebhookInbox.process or the scheduled :meth:~tempest_fastapi_sdk.db.WebhookInbox.drain_once.

    Name Type Description Default

    Where events are recorded.

    		 required
    secret SecretSource | None

    The Authorization value; see :func:make_revenuecat_webhook_dependency.

    		 required
    signing_secret SecretSource | None

    The HMAC signing secret.

    		 None
    on_recorded Callable[[UUID], Awaitable[object]] | None

    Awaited with the inbox id of a newly recorded event — enqueue the processing task here. Not called for a repeat. If it raises, the event is already recorded and the sweep picks it up, so the route still answers 200.

    make_revenuecat_webhook_dependency ¶

    make_revenuecat_webhook_dependency(
    secret: SecretSource | None,
    *,
    signing_secret: SecretSource | None = None,
    tolerance_seconds: int = DEFAULT_SIGNATURE_TOLERANCE_SECONDS,
    error_message: str = "Invalid RevenueCat webhook credentials",
) -> Callable[..., Coroutine[Any, Any, RevenueCatWebhookDelivery]]

    Build a FastAPI dependency that authenticates and parses a delivery.

    Each secret is resolved per request, and every one that resolves to a value must pass. So secret="" with a filled signing_secret is HMAC only, and the reverse is Authorization only — the reading :class:~tempest_fastapi_sdk.settings.RevenueCatSettings applies at boot. When neither resolves to a value the request is refused: emptiness fails closed, it never opens the endpoint.

    Parameters:

    Name Type Description Default
    secret SecretSource | None

    The Authorization value configured in the dashboard, or a function returning it per request. None or a value that resolves to empty skips this check.

    		 required
    signing_secret SecretSource | None

    The HMAC signing secret, when signing is enabled on the integration. None or a value that resolves to empty skips this check.

    		 None
    tolerance_seconds int

    Signature timestamp window, in seconds.

    		 DEFAULT_SIGNATURE_TOLERANCE_SECONDS
    error_message str

    Message of the 401.

    		 'Invalid RevenueCat webhook credentials'

    Returns:

    Type Description
    Callable[..., Coroutine[Any, Any, RevenueCatWebhookDelivery]]

    Callable[..., Coroutine[Any, Any, RevenueCatWebhookDelivery]]: The
    Callable[..., Coroutine[Any, Any, RevenueCatWebhookDelivery]]

    async dependency.

    Raises:

    Type Description
    ValueError

    When both secret and signing_secret are None — that endpoint would accept anyone.
    UnauthorizedException

    (401, from the dependency) When a configured check fails (header missing or wrong), or when neither secret resolves to a value for this request.
    ValidationException

    (422, from the dependency) When an authenticated body is not a valid event.

    SubscriptionStatusEnum ¶

    Bases: BaseStrEnum

    Normalized state of a subscription after one event.

    • TRIAL — active, in a free trial period.
    • ACTIVE — active and paid (or a one-off purchase).
    • CANCELLED — renewal turned off; access normally lasts until period_end.
    • BILLING_ISSUE — a charge failed; not expired. grace_period_end says how long the store keeps trying, when it has a grace period.
    • PAUSE_SCHEDULED — a Google Play pause starts at the end of the period; access continues until then.
    • PAUSED — the pause started; access is gone until it resumes.
    • EXPIRED — access should be removed.
    • REFUNDED — the latest period was refunded.
    • TEMPORARY_GRANT — RevenueCat granted access for at most 24 hours while it could not validate the purchase.
    • NO_CHANGE — a documented event that does not move the state.
    • UNKNOWN — an event type this release does not know.
