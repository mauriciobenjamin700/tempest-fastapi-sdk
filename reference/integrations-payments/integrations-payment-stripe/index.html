    StripeClient(client: HTTPClient)

    Raises:

    Type Description
    StripeError

    When expected_object is given and the successful body's object differs or is missing.

    Writes carry an idempotency key by default. Stripe replays the original response for a repeated key within 24 hours, which is what makes the SDK's own retry policy safe here: without it, a timeout on POST /v1/payment_intents followed by a retry can create two payments.

    StripeObjectMismatchError ¶

    StripeObjectMismatchError(
    *,
    expected_object: str,
    received_object: str,
    status_code: int,
    request_id: str = "",
    payload: Mapping[str, Any] | None = None,
)

    Bases: StripeError

    Raised when a 2xx body is not the kind of object the call asked for.

    Every Stripe object carries its type in object ("customer", "payment_intent", "checkout.session"), and a deleted one keeps the same value next to deleted: true. A body whose object is missing or names another type did not come from the endpoint the resource addresses, so validating it into the resource's model would hand the caller another object's data under the wrong type.

    Subclasses :class:StripeError, so except StripeError keeps catching it. status_code is the (successful) status the body came with; error_type and code stay empty, since Stripe raised nothing.

    Attributes:

    expected_object str

    The object value the resource expects.
    received_object str

    The object value in the body; empty when the key is missing or not a string.

    Build an :class:HTTPClient configured for Stripe.

    Parameters:

    The secret key (sk_live_... / sk_test_...). Sent as a bearer token, which is one of the two schemes the specification declares.

    		 required
    base_url str

    Value for the Stripe-Version header. Change it deliberately, after checking what the newer version alters.

    		 required
    tolerance_seconds int

    Replay window, in seconds.

    		 DEFAULT_TOLERANCE_SECONDS
    error_message str

    		 'Invalid Stripe webhook signature'

    Type Description
    Callable[..., Coroutine[Any, Any, StripeWebhookEvent]]

    Callable[..., Coroutine[Any, Any, StripeWebhookEvent]]
