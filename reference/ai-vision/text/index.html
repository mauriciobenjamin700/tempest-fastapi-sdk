    tempest_fastapi_sdk.text¶

    Busca aproximada de texto sem modelo: normalização, distância de edição e lookup fuzzy.

    « IA e visão computacional

    text ¶

    Text matching without a model: normalization, edit distance, fuzzy lookup.

    For "what did the user mean?" over a known list of names — cities, products, categories — lexical matching answers faster and more predictably than an embedding model: no weights, no GPU, a typo costs one edit. Semantic search over free-form passages lives in :mod:tempest_fastapi_sdk.genai (Embedder, Retriever, HybridRetriever).

    • :func:normalize_text / :func:strip_accents / :func:tokenize — one canonical form (no accents, case folded, punctuation as spaces), tokens with their offsets in the original string.
    • :func:levenshtein / :func:similarity / :func:trigrams — edit distance with adjacent swaps, the 0..1 ratio, the trigram set.
    • :class:FuzzyIndex — names to values, exact and typo-tolerant search through a trigram index.

    No dependency beyond the standard library.

    FuzzyIndex ¶

    FuzzyIndex(entries: Iterable[tuple[str, T]] = ())

    Names mapped to values, searchable exactly and with typos.

    Keys are normalized with :func:~tempest_fastapi_sdk.text.normalize_text on the way in and on every query, so "São Paulo", "sao paulo" and "SAO PAULO" are one key. One key may hold several values (two towns with the same name); every value comes back.

    Example::

    index = FuzzyIndex([("São Paulo", 1), ("Santos", 2)])
index.search("sao paolo")[0].value  # 1

    Build the index.

    levenshtein ¶

    levenshtein(left: str, right: str, *, limit: int | None = None) -> int

    Return the edit distance between two strings.

    Insert, delete and substitute cost one each, and so does swapping two adjacent characters ("paolo" -> "paulo" is one substitution, "soa" -> "sao" one swap): the optimal-string-alignment distance, which matches the way people mistype.

    Parameters:

    Name Type Description Default
    left str

    One string.

    		 required
    right str

    The other.

    		 required
    limit int | None

    Stop early and return limit + 1 once every path is already longer than limit. With a limit only the cells within limit of the diagonal are computed (no path that leaves that band can come back under the limit), so the cost is O(len * limit) instead of O(len * len). None computes the exact distance.

    		 None

    Returns:

    Name Type Description
    int int

    The number of edits; limit + 1 when limit is given and
    int

    exceeded.

    trigrams(text: str) -> frozenset[str]

    The string is padded with one space on each side, so the first and last letters take part ("rio" -> {" ri", "rio", "io "}) and even a one- or two-letter string has a trigram.
