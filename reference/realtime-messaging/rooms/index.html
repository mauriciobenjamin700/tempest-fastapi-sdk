    The rules every room of a registry follows.

    Attributes:

    Name Type Description
    max_players int

    Slots per room, 2 to 255.
    protocol_version str | None

    Version every client must announce on create / join; a mismatch is refused with version_mismatch. None accepts any.
    reconnect_grace_seconds float

    How long a dropped player's seat is kept for a resume; 0 removes it at once.
    messages_per_second float

    Sustained relay rate allowed per player, JSON and binary together (token bucket).
    burst int

    Messages a player may send at once above the rate.
    max_rooms int

    Rooms the registry holds at most.
    code_length int

    Characters in a room code, 4 to 12.
    lock_when_playing bool

    Refuse join while the room is playing; a resume is always allowed.
    allowed_message_types frozenset[str] | None

    When set, a relayed JSON data must be an object whose type is listed here.
    max_name_length int

    Characters kept of a player name.

    Raises:

    When a bound is out of range.
