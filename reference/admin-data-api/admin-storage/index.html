    tempest_fastapi_sdk.admin.storage¶

    A fonte de dados do navegador de storage do admin: um bucket de object store.

    « Admin, dados e API

    storage ¶

    The storage browser's data source: one bucket of an object store.

    The admin already wrote to object storage (upload_fields=) and the CLI already read it (tempest storage ls), but an operator who needed to see what a bucket holds, look at one file or remove a stray upload had no screen for it. :class:StorageBrowserService is that screen's service: it lists a "folder", describes one object, decides how the object can be previewed, and carries out the writes — upload, replace, rename, in-place text edit and delete — with the limits checked here rather than in the template.

    It talks to any store with the five calls of :class:AdminStorageClient, which :class:~tempest_fastapi_sdk.storage.AsyncMinIOClient and :class:~tempest_fastapi_sdk.storage.LocalObjectStorageClient both implement. Folders are not objects on either: they are the /-separated prefixes of the keys, so an empty folder does not exist and a folder appears as soon as one key is written under it.

    What the browser deliberately does not do is serve a stored file as a page of the admin's origin. Previews go through :func:~tempest_fastapi_sdk.storage.object_download_response, which grants inline only to :data:~tempest_fastapi_sdk.utils.INLINE_SAFE_MEDIA_TYPES and stamps nosniff plus a sandboxing CSP on every response. Text-like types outside that list — HTML, SVG, JSON — are previewed as escaped source in the page, never rendered.

    DEFAULT_STORAGE_PAGE_SIZE module-attribute ¶

    DEFAULT_STORAGE_PAGE_SIZE: Final[int] = 100

    Entries (folders and files) shown per page of a folder listing.

    DEFAULT_STORAGE_MAX_UPLOAD_BYTES module-attribute ¶

    DEFAULT_STORAGE_MAX_UPLOAD_BYTES: Final[int] = 25 * 1024 * 1024

    Largest file the browser accepts in one upload or replace: 25 MiB.

    The same figure as :data:~tempest_fastapi_sdk.storage.DEFAULT_LOCAL_MAX_UPLOAD_BYTES, so a store and its admin screen refuse at the same size by default.

    DEFAULT_STORAGE_MAX_TEXT_BYTES module-attribute ¶

    DEFAULT_STORAGE_MAX_TEXT_BYTES: Final[int] = 256 * 1024

    Largest text object previewed in the page and editable in place: 256 KiB.

    A bigger file is still downloadable and replaceable; it is only kept out of a <textarea>, where a multi-megabyte log would make the page unusable.

    STORAGE_KEY_MAX_BYTES module-attribute ¶

    STORAGE_KEY_MAX_BYTES: Final[int] = 1024

    Longest key accepted, in UTF-8 bytes — the S3 object-key limit.

    STORAGE_SPOOL_BYTES module-attribute ¶

    STORAGE_SPOOL_BYTES: Final[int] = 8 * 1024 * 1024

    Bytes an upload or copy keeps in memory before spilling to a temp file.

    STORAGE_STAT_CONCURRENCY module-attribute ¶

    STORAGE_STAT_CONCURRENCY: Final[int] = 8

    Concurrent stat_object calls made while describing one listing page.

    TEXT_MEDIA_TYPES module-attribute ¶

    TEXT_MEDIA_TYPES: Final[frozenset[str]] = frozenset(
    {
        "application/csv",
        "application/javascript",
        "application/json",
        "application/ld+json",
        "application/sql",
        "application/toml",
        "application/x-ndjson",
        "application/x-sh",
        "application/x-yaml",
        "application/xml",
        "application/yaml",
        "image/svg+xml",
    }
)

    Types outside text/* that are text and preview as source.

    image/svg+xml is here on purpose: it is never served inline (it can carry <script>), so the only safe preview is its escaped source.

    StoragePreviewEnum ¶

    Bases: BaseStrEnum

    How the object page previews a stored object.

    IMAGE, VIDEO, AUDIO and PDF are rendered by the browser from the raw route, and only for types in :data:~tempest_fastapi_sdk.utils.INLINE_SAFE_MEDIA_TYPES. TEXT is the escaped source in the page. NONE offers the download only.

    StorageBrowserError ¶

    Bases: ValueError

    A browser operation refused for a reason the operator can fix.

    The message is shown on the page as is, so it names the key and the limit rather than the exception type.

    StorageObjectMissingError ¶

    Bases: StorageBrowserError

    The object the operation names is not stored (any more).

    AdminStorageClient ¶

    Bases: Protocol

    The object-store calls :class:StorageBrowserService makes.

    :class:~tempest_fastapi_sdk.storage.AsyncMinIOClient and :class:~tempest_fastapi_sdk.storage.LocalObjectStorageClient satisfy it; it is also a :class:~tempest_fastapi_sdk.storage.DownloadableStore, which is what the raw route streams from. Parameter names are the SDK clients' own.
