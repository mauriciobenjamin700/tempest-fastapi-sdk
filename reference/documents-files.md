# Referência: Documentos e arquivos

## Módulos

Uma página por módulo; cada uma renderiza a API pública dele a partir das docstrings.

| Módulo | O que cobre |
| --- | --- |
| [`artifacts`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/artifacts.md) | Registro de artefatos binários versionados: no banco, ativáveis e com digest. |
| [`pdf`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/pdf.md) | Geração de PDF a partir de templates HTML. |
| [`privacy`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/privacy.md) | Exportação e apagamento de dados do titular (LGPD art. 18, GDPR art. 15/17). |
| [`share`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/share.md) | Prévia de link compartilhado: a página Open Graph e a imagem do card. |
| [`slides`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/slides.md) | Slides, gabaritos e documentos Markdown em PDF a partir de texto puro. |
| [`spreadsheet`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/spreadsheet.md) | Geração de planilhas `.xlsx` que o destinatário consegue usar. |
| [`storage`](https://mauriciobenjamin700.github.io/tempest-fastapi-sdk/reference/documents-files/storage.md) | Object storage (MinIO, S3 ou disco local), upload resumível (tus) e os clientes de storage. |
