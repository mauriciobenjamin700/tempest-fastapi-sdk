    Migration guide¶

    Breaking-change walkthroughs grouped by minor release. Stick to the version that matches what you're upgrading from. The subpages, and the release sections inside each one, are listed newest-first, so on a multi-version jump read and apply them bottom-up.

    Version ranges¶

    One subpage per minor-version range, newest first.

    Subpage What it solves
    Migration 0.37x Use when upgrading from a version older than these releases: 0.374.0, 0.373.0 and 0.372.0.
    Migration 0.36x Use when upgrading from a version older than these releases: 0.366.0 and 0.361.0.
    Migration 0.34x–0.35x Use when upgrading from a version older than these releases: 0.353.0, 0.349.0, 0.344.0, 0.343.0, 0.342.0, 0.341.0 and 0.340.0.
