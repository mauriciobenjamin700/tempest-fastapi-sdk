[`mkdocstrings`](https://mkdocstrings.github.io/), so it reads the same in every
UI language. To avoid duplicate symbol anchors, the rendered reference is
published a single time, on the default-language pages. Each theme below is an
index, and each module has its own page (one page per theme reached 22 MB of
HTML, #878):

!!! tip "Searching"
    Every public symbol exported by `tempest_fastapi_sdk` is documented there
    with its full signature, parameters, return type and raised exceptions;
    the source lives in the repository and in the installed package. Use the
    search bar (or press `/`) to jump to a symbol by name — the full-text
    index includes the docstrings.
