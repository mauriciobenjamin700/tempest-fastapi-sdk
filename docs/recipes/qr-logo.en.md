# QR code with a logo (ride link)

A QR code printed on the car window, on a poster at the bus station or on the
driver's screen takes the passenger straight to the ride. With the brand's
logo in the middle, it also says whose link it is before anyone points a
camera at it.

The logo covers modules of the QR code. **Error correction** makes up for
that: level `H` recovers up to 30% of the symbol. This recipe generates the
QR code at level `H`, pastes the logo on a white frame in the middle, at a
size that was measured to keep reading, and serves the image from a route.

By the end you will have:

- `qr_with_logo(url, logo)`: the PNG of the QR code with the logo in the
  middle;
- `GET /caronas/{trip_id}/qr.png`: each ride's QR code, pointing at its
  [share page](share-preview.md);
- a test that decodes the generated QR code, so the logo never grows past
  what still reads.

## Installation

The QR code is generated by [`segno`](https://pypi.org/project/segno/), pure
Python with no dependencies. The logo is pasted with Pillow, from the
`[image]` extra:

```bash
uv add "tempest-fastapi-sdk[image]" segno
```

## Step 1: the QR code with the logo

```python
import io
from pathlib import Path

import segno
from PIL import Image

LOGO_FRACTION: float = 0.25
QR_SCALE: int = 10
QR_BORDER: int = 4
LOGO_PADDING: int = 10


def qr_with_logo(url: str, logo: Path, *, logo_fraction: float = LOGO_FRACTION) -> bytes:
    qr = segno.make(url, error="h", micro=False)
    buffer = io.BytesIO()
    qr.save(buffer, kind="png", scale=QR_SCALE, border=QR_BORDER)
    image = Image.open(buffer).convert("RGB")

    side = qr.symbol_size(scale=QR_SCALE, border=0)[0]
    logo_side = int(side * logo_fraction)
    mark = Image.open(logo).convert("RGBA")
    mark.thumbnail((logo_side, logo_side), Image.Resampling.LANCZOS)

    frame = Image.new(
        "RGB",
        (mark.width + 2 * LOGO_PADDING, mark.height + 2 * LOGO_PADDING),
        "white",
    )
    frame.paste(mark, (LOGO_PADDING, LOGO_PADDING), mark)
    image.paste(
        frame,
        ((image.width - frame.width) // 2, (image.height - frame.height) // 2),
    )

    output = io.BytesIO()
    image.save(output, format="PNG")
    return output.getvalue()
```

The result, with the link `https://app.buscar.com.br/s/42` and a 400×400
logo:

![Black and white QR code with a rounded blue square and a yellow letter B in the middle](../assets/qr-logo.png)

Piece by piece:

- **`error="h"`** is what makes room for the logo. Without it, `segno` 1.6.6
  picked `L` (7% recovery) for this recipe's links. At `H` the QR code is
  denser (more modules for the same link), and that redundancy is what the
  logo spends.
- **`micro=False`** rules out Micro QR, which `segno` picks for very short
  text (for `"42"` it produced an `M1`) and which phone readers generally do
  not support.
- **`symbol_size(..., border=0)`** is the side of the QR code **without** the
  white border. The logo is sized against that side, not the whole image.
- **`thumbnail`** shrinks the logo keeping its aspect ratio. A wide logo ends
  up short; it never leaves the reserved square.
- **The white frame** (`LOGO_PADDING`) separates the logo from the modules
  around it. Without it, a dark logo touching the black modules confuses the
  reader about where each module ends.

## How much logo fits

Measured with `segno` 1.6.6 and `zxing-cpp` 3.1.1. Setup: level `H` QR code,
`scale=10`, square opaque logo on a 10 px white frame, and two links, one of
30 characters (QR version 4) and one of 64 (version 7). "Degraded" is the
image shrunk and blurred, in four combinations (shrinking from 1/2 to 1/4,
Gaussian blur from 0.6 to 1.0 px), to imitate a camera photo:

| Logo side (fraction of the QR) | Area covered | 30-char link: clean / degraded | 64-char link: clean / degraded |
| --- | --- | --- | --- |
| 20% | 4% | reads / 4 of 4 | reads / 4 of 4 |
| 25% | 6% | reads / 4 of 4 | reads / 4 of 4 |
| 30% | 9% | reads / 4 of 4 | reads / 4 of 4 |
| 35% | 12% | reads / 4 of 4 | reads / 4 of 4 |
| 40% | 16% | fails / 0 of 4 | reads / 2 of 4 |
| 45% | 20% | fails / 0 of 4 | fails / 0 of 4 |

The default `LOGO_FRACTION = 0.25` sits two steps below the first one that
failed (40%). The margin is for what the measurement does not reproduce:
glare on the window, low-resolution printing, an old phone camera.

!!! warning "This measures a reader, not a camera"
    The table was measured by decoding the image with `zxing-cpp`, not by
    pointing a phone at it. Before printing in bulk, test the final QR code
    with two or three different cameras, at the distance and in the light
    where it will be read.

Two choices outside the logo matter too:

- **Link length.** The 30-character link became a version 4 QR code (33×33
  modules), and the 64-character one a version 7 (45×45). At the same printed
  size, more modules are smaller modules, and the camera has to come closer.
  Prefer `/s/42` to a URL with a UUID and campaign parameters. In the table,
  both read at 25%.
- **Colors.** The table was measured with black modules on a white
  background. Put the brand color in the logo and keep the QR code black and
  white. Other combinations were not measured.

## Step 2: each ride's QR code

The QR code should point at the ride's **share page** (`/s/{id}`, from the
[Sharing with a preview](share-preview.md) recipe), not at the app directly.
Whoever scans it lands in the browser, and the page takes them to the app.
The same link, pasted into WhatsApp, shows the preview with the card.

```python
import io
from pathlib import Path

import segno
from fastapi import FastAPI, HTTPException, Response
from PIL import Image

PUBLIC_URL: str = "https://app.buscar.com.br"
LOGO: Path = Path("static/logo.png")
TRIPS: set[str] = {"42"}
LOGO_FRACTION: float = 0.25
QR_SCALE: int = 10
QR_BORDER: int = 4
LOGO_PADDING: int = 10


def qr_with_logo(url: str, logo: Path, *, logo_fraction: float = LOGO_FRACTION) -> bytes:
    qr = segno.make(url, error="h", micro=False)
    buffer = io.BytesIO()
    qr.save(buffer, kind="png", scale=QR_SCALE, border=QR_BORDER)
    image = Image.open(buffer).convert("RGB")
    side = qr.symbol_size(scale=QR_SCALE, border=0)[0]
    logo_side = int(side * logo_fraction)
    mark = Image.open(logo).convert("RGBA")
    mark.thumbnail((logo_side, logo_side), Image.Resampling.LANCZOS)
    frame = Image.new(
        "RGB",
        (mark.width + 2 * LOGO_PADDING, mark.height + 2 * LOGO_PADDING),
        "white",
    )
    frame.paste(mark, (LOGO_PADDING, LOGO_PADDING), mark)
    image.paste(
        frame,
        ((image.width - frame.width) // 2, (image.height - frame.height) // 2),
    )
    output = io.BytesIO()
    image.save(output, format="PNG")
    return output.getvalue()


app = FastAPI()


@app.get("/caronas/{trip_id}/qr.png", response_class=Response)
async def trip_qr(trip_id: str) -> Response:
    if trip_id not in TRIPS:
        raise HTTPException(status_code=404)
    png = qr_with_logo(f"{PUBLIC_URL}/s/{trip_id}", LOGO)
    return Response(
        png,
        media_type="image/png",
        headers={"Cache-Control": "public, max-age=86400"},
    )
```

A ride's QR code does not change: the link is the same for as long as the
ride exists. Hence the long `Cache-Control`. Generating a QR code with a logo
took about 7 ms (mean of 50, 64-character link, same machine as the table),
so it is not worth storing on disk, but there is no reason to redo it on
every visit either.

For large prints, raise `QR_SCALE` (pixels per module) instead of resizing
the PNG afterwards: enlarging the finished image blurs the module edges.

## Step 3: the test that keeps the logo from growing

The logo size is the kind of number someone bumps "just a little" so the
brand shows more. A test that **decodes** the generated QR code turns that
limit into a CI failure:

```python
import io
from pathlib import Path

import zxingcpp
from PIL import Image

from app.qr import qr_with_logo


def test_qr_with_logo_still_decodes(tmp_path: Path) -> None:
    logo = tmp_path / "logo.png"
    Image.new("RGBA", (300, 300), (11, 61, 145, 255)).save(logo)
    url = "https://app.buscar.com.br/s/42"

    png = qr_with_logo(url, logo)

    decoded = zxingcpp.read_barcodes(Image.open(io.BytesIO(png)))
    assert [result.text for result in decoded] == [url]
```

Install the reader in the development group only:
`uv add --dev zxing-cpp`.

## Recap

- **Level `H`** (`segno.make(url, error="h", micro=False)`) is what lets the
  logo cover part of the QR code.
- **Logo at 25% of the QR code's side** (6% of the area), on a white frame.
  In the measurement, up to 35% read in every case, and at 40% the short link
  already failed.
- **The QR code points at `/s/{id}`**, the share page: whoever scans it
  reaches the app, and the same link has a preview on WhatsApp.
- **A test decodes the QR code** with `zxing-cpp`, so the logo does not grow
  past what reads.
- **Before printing**, test with real cameras.
