!!! tip "Searching"
    Every public symbol exported by `tempest_fastapi_sdk` is documented there
    with its full signature, parameters, return type and raised exceptions;
    the source lives in the repository and in the installed package. Use the
    search bar (or press `/`) to jump to a symbol by name — the full-text
    index includes the docstrings.
